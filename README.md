# BrickSeekr
Brickseekr is a web-based platform for comparing LEGO set prices and evaluating their investment potential.

The application aggregates offers from multiple marketplaces and analyzes them using a custom investment scoring model. This allows users to identify underpriced sets, compare deals efficiently, and make more informed purchasing decisions based on data rather than speculation.

The project was developed as a proof-of-concept (PoC) within a master’s thesis focused on alternative investments and the growing market of collectible assets such as LEGO sets. Its primary goal is to improve transparency, reduce manual research, and make LEGO investing more accessible to a broader audience.

## Tech Stack

### Frontend
- React
- Vite
- JavaScript (ES6+)
- CSS (responsive design)

### Backend
- FastAPI (Python)
- REST API architecture
- Asynchronous processing

### Data & Integration
- Web scraping (multiple e-commerce sources)
- External APIs (e.g. BrickLink, BrickEconomy)
- Data aggregation and normalization

### Database
- PostgreSQL
- SQLAlchemy (ORM)

### Infrastructure
- Docker / Docker Compose
- Local development via Node.js and npm
